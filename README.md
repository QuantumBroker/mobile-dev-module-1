# Модульний контроль №1 з мобільної розробки

Практичні завдання виконані мовою Dart/Flutter.

## Структура коду:
- `task1.dart` — Завдання 1: Класи та колекції (Library)
- `task2.dart` — Завдання 2: Stateless-віджет (RatingBadge)
- `task3.dart` — Завдання 3: State Management та Навігація
- `task4.dart` — Завдання 4: Асинхронний код (WeatherService)

---

## Використання ШІ

Під час виконання роботи використовувалися інструменти штучного інтелекту (Gemini) для прискорення розробки та валідації рішень.

* **Мета використання:** Консультація щодо архітектурних підходів Flutter, перевірка синтаксису Dart та оптимізація обробки винятків.
* **Основні запити (промпти):** Запити стосувалися структурування класів відповідно до вимог завдання, налаштування навігації `Navigator.push/pop` та генерації асинхронного потоку даних (`Stream`).
* **Власний інтелектуальний внесок:** 
  - Проведено тестування та інтеграцію отриманих кодових фрагментів у середовищі DartPad.
  - Налаштовано точки входу `main()` та обгортки віджетів `MaterialApp/Scaffold`.
  - Валідовано обробку крайніх випадків (обмеження значень рейтингу через `.clamp()`, перевірка порожніх рядків у сервісі погоди).
  - Проведено повне тестування роботи застосунків та підготовлено демонстраційне відео розбору коду.
